# REGULAR GRAVITy 🚀

> An unofficial, lightweight Electron desktop environment for seamlessly bridging Web AI interfaces with your local codebase and development workflow.

---

## 🌟 Key Features

- **Direct Web AI Launch**: Skip friction and instantly connect to Google Gemini and other AI tools.
- **Smart Command Parsing**: Automatically detects `[CMD: ...]` and `[REQUEST: ...]` blocks from AI responses.
- **Unified Action Deck**: Safely review and execute file read/write/edit and terminal commands locally.
- **Multi-Line Code Editor**: Full raw code editing, targeted block editing (`✏️`), and real-time disk file watching.
- **Payload Management**: Automatically prepares temporary project briefing bundles (`SendingMD/`) for efficient AI context delivery.

---

## 🚀 Getting Started

### Prerequisites
- Node.js (v16 or higher)
- npm

### Installation & Running

```bash
# Clone the repository
git clone https://github.com/johnyu1211/RegularGravity.git
cd RegularGravity

# Install dependencies
npm install

# Start application
npm start
```

Or double-click `run.bat` on Windows.
